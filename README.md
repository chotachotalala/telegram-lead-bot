# Telegram Lead Bot

Учебный Telegram-бот на Python и aiogram 3 для сбора заявок на услуги.

## Возможности

- Выбор услуги из списка в `bot_config.json`.
- Последовательный сбор имени и контактных данных.
- Проверка телефона, email и Telegram username.
- Подтверждение заявки перед сохранением.
- Отмена заявки кнопкой или командой `/cancel`.
- Сохранение подтверждённых заявок в `leads.json`.
- Отправка уведомления администратору из `bot_config.json`.
- Проверка конфигурации при запуске.

## Требования

- Python 3.10 или новее.
- Токен Telegram-бота, полученный через [@BotFather](https://t.me/BotFather).

## Установка

Откройте терминал в корневой директории проекта.

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Linux и macOS:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Настройка токена

Создайте файл `.env` в корневой директории проекта.

Добавьте в него токен:

```dotenv
BOT_TOKEN=ваш_токен_от_BotFather
```

Замените значение на настоящий токен своего бота.

Не публикуйте токен и не добавляйте файл `.env` в Git.

## Настройка бота

Откройте `bot_config.json`.

Пример конфигурации:

```json
{
  "bot_name": "Telegram Lead Bot",
  "admin_id": 123456789,
  "welcome_message": "Здравствуйте! Выберите услугу:",
  "services": [
    "Telegram-бот",
    "AI-бот",
    "Автоматизация"
  ]
}
```

Замените `123456789` на настоящий числовой Telegram ID администратора.

Измените `welcome_message` и список `services` под свой проект.

Все обязательные поля должны присутствовать, а список услуг не должен быть пустым.

## Запуск

Выполните команду из корневой директории проекта:

```bash
python bot.py
```

После успешного запуска откройте бота в Telegram и отправьте:

```text
/start
```

## Как работает заявка

1. Пользователь выбирает услугу.
2. Вводит имя.
3. Вводит телефон, email или Telegram username.
4. Проверяет введённые данные.
5. Нажимает «Подтвердить» или «Отменить».

Заявка сохраняется только после подтверждения.

## Хранение заявок

Подтверждённые заявки записываются в `leads.json` в корневой директории проекта.

В записи сохраняются услуга, имя, контакт, Telegram ID пользователя, username и время создания заявки в UTC.

Файл создаётся автоматически при первой успешной записи. Если файл содержит некорректный JSON или не удаётся сохранить данные, бот не сообщает пользователю об успешном сохранении.

Файл `leads.json` исключён из Git, поскольку содержит персональные данные клиентов.

## Ручная проверка

Перед использованием проверьте следующие сценарии:

- Выбор доступной услуги и заполнение корректной заявки.
- Ввод слишком короткого имени.
- Ввод некорректного телефона, email или username.
- Подтверждение и сохранение заявки.
- Отмена через кнопку и команду `/cancel`.
- Получение уведомления администратором.
- Сохранение нескольких заявок в одном файле.
- Повторный запуск бота с уже существующим `leads.json`.
- Обработка отсутствующей или повреждённой конфигурации.
- Обработка ошибки сохранения заявки.
